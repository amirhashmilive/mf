01 · Overview

A monthly visual log of fieldwork

The Project Gallery is a chronological record of recent Meer Foundation fieldwork. Unlike the Media Gallery (which is a permanent archive of finished photographs and films), this page is a refreshable log — twelve projects from the last twelve months, updated monthly.

Monthly refresh

Twelve projects from the last twelve months. The log rolls forward — older projects rotate out as newer ones come in. The Media Gallery is the permanent archive.

Six categories

Filter by programme — Bolti Nadi, Farmours, Prayaas, Yoga Kutumb, Heritage, Tiranga. Each card carries its category as a coloured badge.

Tagged for context

Beyond the category filter, each project carries 2–3 descriptive tags — 'erosion', 'women-led', 'world-record' — for finer browsing.

Image placeholders — by design

03 · Awareness

Why a visual log matters

A visual log is not a portfolio. It is a receipt. These slides explain the principles that govern what gets logged, how it gets tagged, and what stays out.

Logging principles
12
Rolling twelve-month window
Projects

The gallery shows the most recent twelve projects. Older projects rotate into the permanent Media Gallery archive. The log is a window, not a vault.

Real locations

Every project carries a real location and date. No composite narratives. No undated 'recent' fields.

No vanity metrics

The log records what happened — not how impressive it was. Outcome metrics live on the Case Studies page.

Editorial-use ready

Journalists can draw from the log directly. Each entry is dated, located, and tagged for editorial citation.
