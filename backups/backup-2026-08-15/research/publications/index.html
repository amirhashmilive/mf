Overview

A catalogue built one field-tested book at a time

Meer Foundation does not publish to publish. Every title in this catalogue was tested in the field — in a village, on a river walk, in a gram sabha — before it was committed to print. The result is a 10-title, 14-year, 1,184-page corpus that scholars, journalists, sarpanches, and CSR teams actually use.

Citation Guide

How to cite us

All Meer Foundation publications should be cited using APA 7th edition. Below: a sample citation, the fields to swap, and a one-click copy for the example.

Sample citation (APA 7th)

Meer Foundation. (2022). The Five Pillars Framework: A Meta-Framework for Institutional Legitimacy. Meer Foundation. https://meerfoundation.org/research/publications
Author: Use the named author where given; otherwise “Meer Foundation”.
Year: Use the publication year shown on the catalogue card.
Title: Italicise in academic use; the catalogue provides the canonical form.
URL: Use the canonical URL: meerfoundation.org/research/publications.

BibTeX

A BibTeX entry is available on each publication page; copy-paste into your .bib file. Type is set to @book for monographs and @techreport for reports.

RIS / EndNote

An RIS file is downloadable from each publication page; import directly into EndNote, Zotero, Mendeley, or any reference manager that supports RIS.
